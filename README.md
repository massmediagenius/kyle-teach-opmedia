# Kyle Teach × OPMEDIA — Brand Strategy Deck

A one-page presentation site that diagnoses Kyle Teach's (@kyle.teacher) current Instagram brand and presents OPMEDIA's strategic overhaul.

## Stack
- Next.js 16 (App Router · Turbopack)
- React 19
- Tailwind CSS v4
- Motion (formerly framer-motion)
- TypeScript

## Local dev

```bash
npm install
npm run dev
```

## Brand colors
- Matte Black `#0A0A0A`
- Charcoal `#1C1C1C`
- Ivory `#F5F1EA`

- Electric Yellow `#F7C204`
